# Day 7 – Claude Model Selection & Reasoning Effort

## Objective

Learn how to choose the right Claude model and reasoning effort level for different tasks to improve output quality, efficiency, and productivity.

---

## What Is Model Selection?

Claude offers multiple models designed for different types of work. Choosing the correct model helps you get better results while making efficient use of available resources.

Instead of using the same model for every task, select the model that best matches the complexity and importance of the work.

---

## Claude Models

### Claude Haiku 4.5

Best for fast, lightweight tasks where speed matters more than deep reasoning.

**Examples**
- Quick factual lookups
- Simple coding questions
- Grammar and spelling checks
- Short summaries

**Avoid using Haiku for:**
- Complex debugging
- Career planning
- System design
- Strategic decision-making

---

### Claude Sonnet 4.6

The best balance of intelligence, speed, and efficiency. Suitable for most everyday tasks.

**Examples**
- Coding and debugging
- Learning new concepts
- Resume improvement
- Portfolio building
- Interview preparation
- Content creation

**Recommended for most users.**

---

### Claude Opus 4.1

Designed for deep reasoning and complex problem-solving.

**Examples**
- Research projects
- System architecture
- Career strategy
- Advanced planning
- High-stakes decision-making

**Use Opus when maximum quality and reasoning are required.**

---

## What Is Reasoning Effort?

Reasoning effort determines how much thinking Claude performs before generating a response.

Different effort levels allow you to balance response speed with output quality.

---

## Effort Levels

### Low

Use for:
- Quick lookups
- Simple questions
- Basic tasks

### Standard

Use for:
- Daily coding
- Learning
- Content creation
- General productivity

### High

Use for:
- Complex debugging
- Resume reviews
- Project planning
- Detailed analysis

### Max

Use for:
- Research
- System design
- Strategic decisions
- Advanced problem-solving
